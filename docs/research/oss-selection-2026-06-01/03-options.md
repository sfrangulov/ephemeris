# 03 · Diverge — Option Generation

date: 2026-06-01
constraint from Phase 2: **grounded** (AI phrases/packages REAL ephemeris data only) ·
shareable · cheap pre-gen+cache · funnels to `/u/<login>` connections · blind-A/B gated.

Categories adapted from the skill to "AI feature for an existing product":
Extension (in-product surface) · Adjacent (new ephemeris surface, npm-maintainer audience) ·
Universal (cross-ecosystem, any GitHub dev — widest viral reach) · Standalone spoke
(separate micro-artifact funnelling back).

> Breadth only — not filtered, not ranked. 12 options, ≥1 per category.

## Extension (in-product: existing `/u` page + badges)

1. **weekly-line** — one grounded auto-generated terse line summarizing the maintainer's week
   ("3 up · docx-to-md +12% w/w · 1.2k new dl"), rendered into the existing badge/card. AI
   phrases real numbers, nothing else.
2. **delta-blurb** — per-package honest one-sentence "what changed" grounded in real
   download/star/version deltas; no "why".

## Adjacent (new ephemeris surface, npm-maintainer audience)

3. **wrapped** — "npm quarter/year in review" shareable card grounded in real download/star
   history; AI phrases highlights ("busiest week", "fastest-growing pkg"). Spotify-Wrapped
   shape, honest register. Seasonal virality → links to `/u`.
4. **version-migration** — grounded in per-version download-share (the killer dataset now
   shipping): "v4 holds 62%, v5 at 18% and rising"; AI phrases the real migration. Embeddable
   per-package, screenshot-worthy.
5. **eco-relative** — honest relative phrasing ("top decile of your category by dl growth")
   with the mandatory honesty caveat. ⚠️ percentile is honesty-hostile (research Tier-3);
   included for breadth, likely cut.

## Universal (cross-ecosystem, any GitHub repo/dev — widest reach)

6. **repo-pulse** — grounded card for ANY GitHub repo (public stars / release cadence /
   recency): terse honest status ("active: 3 releases/90d, ★ +5% w/w"). Works beyond the
   owner → broad shareability; funnels to "track your own → claim /u".
7. **maintained?** — evaluator-facing honesty card for any npm package grounded in real
   release cadence + download trend ("last publish 14d ago · dl flat"). Viral "check before
   you npm install" angle.
8. **compare-card** — two packages side by side, honest phrasing of real relative dl/star
   trends (npm-trends-like but honest + AI headline + shareable). Evaluator-facing.

## Standalone spoke (separate micro-artifact → ephemeris funnel)

9. **npx-card** — `npx ephemeris-card <npm-user>` prints a grounded, AI-captioned portfolio
   card + an embed snippet + a claim-your-`/u` link. npm-pets DNA, but honest + funnelling.
10. **readme-strip** — standalone page: paste npm username → grounded AI-captioned embeddable
    README strip → claim profile.

## Cross-cut (authoring-adjacent but grounded — serves the launch vehicle)

11. **post-draft** — generates a ready-to-share honest one-liner from real momentum deltas, in
    Sergei's plain voice, that the maintainer posts; the post links back to `/u`. Directly
    feeds the "viral post → connection" loop. (Authoring, but strictly grounded.)
12. **silent-proof** — grounded "proof-of-impact against a silent userbase" artifact (the
    top maintainer JTBD): "847 people downloaded your work this week and never said a word",
    phrased honestly from real counts. Emotional + shareable.
